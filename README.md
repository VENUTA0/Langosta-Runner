# Langosta Run
Runner de esquivar obstáculos hecho con Unity 2022.3.62f2 y C#.

## Qué incluye
- Movimiento del jugador 
- Obstáculos que aparecen aleatoriamente
- Contador de puntos
- Pantallas de inicio y game over
