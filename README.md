# Langosta Run 
Endless runner 3D de esquivar obstáculos hecho con **Unity 2022.3.62f2** y **C#**.

## Qué incluye
- Control híbrido del jugador (movimiento libre con teclado `WASD` o flechas direccionales).
- Generación aleatoria y continua de obstáculos mediante *prefabs*.
- Contador de distancia recorrida en tiempo real y puntuación final al terminar la partida.
- Interfaz completa escalable (`960x540`) con pantalla de inicio, HUD en partida y menú de *Game Over* con reinicio instantáneo.

## Qué hice yo
Programación en C#, lógica de aparición de obstáculos y colisiones, diseño de escenario, interfaz de usuario (UI), optimización WebGL y publicación.

## Qué aprendí
Aprendí a estructurar un juego completo desde cero en Unity, gestionar el ciclo de vida de la partida con `Time.timeScale`, instanciar y destruir *prefabs* dinámicamente, generar controles para PC  y optimizar las sombras y el rendimiento para exportar a WebGL.
